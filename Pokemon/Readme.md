#  Pokémon Legendary Classification 

Project ini bertujuan untuk membangun model Machine Learning yang mampu memprediksi secara akurat apakah sebuah Pokémon berstatus **Legendaris** atau tidak berdasarkan karakteristik fisik dan statistik bertarungnya.

---

## 🎯 Ringkasan Proyek
* **Dataset:** 801 baris data Pokémon (Generasi 1-7).
* **Algoritma :** XGBoost Classifier.
* **Hasil Akhir:** Model meraih akurasi dan F1-Score sempurna **1.0 (100%)** pada Data Train maupun Data Test secara valid.
